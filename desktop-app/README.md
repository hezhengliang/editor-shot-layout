# DieLayoutEditor Desktop (egui 复刻)

基于 [eframe/egui](https://github.com/emilk/egui) 的桌面版 Shot/Die 布局编辑器,复刻 web 版(`../src`)的核心交互与几何语义(单位 μm,3 位小数)。

## 已实现(与 web 版对齐)

- 无限画布 + 标尺(刻度自适应缩放,十字线 + 坐标读数,选中范围高亮,尺寸 pill 收在标尺带内)
- 世界原点在标尺左上角,不允许负坐标(视图钳制)
- Shot 容器:虚线外框、槽位棋盘格、内边距虚线边界;尺寸由内部 Die 推导(列宽=该列最宽 Die)
- Die 槽位模型:一个槽位一颗 Die,槽位内水平垂直居中;相邻 Die 间距标注(粉),外圈 scribe/容器尺寸标注(灰/蓝)
- 拖放:左侧 Die 模板/Shot 卡片拖入画布(带落点提示与拒绝原因浮签),双击卡片自动放置
- 手势:滚轮缩放(指针锚点)、空白拖拽平移、拖动 Shot 吸附 CELL 网格(碰撞还原)、拖动 Die 换槽位、双击 Shot 隔离(Esc 退出)、Delete 删除
- 右侧面板:信息/配置 Tab + 底部固定操作区;排布预设(2×2 / 4×4 / 4×8 / 2×6 / 6×4)、填充空槽、scribe 参数即时生效(非法还原)
- 顶栏状态提示;light/dark 主题切换;右下角工具栏(− / % / + / 自适应)
- 启动时自动加载系统中文字体(PingFang / 冬青黑),中文正常显示

## 与 web 版的差异(暂未实现)

- 无 Tweakpane(用 egui 原生控件替代);无 resize 手柄(Die 尺寸在右侧面板改)
- 无参考曝光场、无模板持久化(内存态)、无晶圆图/BitMap 视图

## 运行

```bash
cargo run --release
```

首次编译依赖较多(eframe/wgpu),请耐心等待。
